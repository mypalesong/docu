# Neo4j 소개

## 그래프 데이터베이스란?

그래프 데이터베이스는 데이터를 **노드(Node)**와 **관계(Relationship)**의 형태로 저장하는 데이터베이스입니다. 이는 실제 세계의 데이터가 서로 연결되어 있는 방식을 자연스럽게 반영합니다.

### 관계형 데이터베이스 vs 그래프 데이터베이스

| 특성 | 관계형 DB | 그래프 DB |
|------|-----------|-----------|
| 데이터 모델 | 테이블, 행, 열 | 노드, 관계, 속성 |
| 관계 표현 | 외래 키, JOIN | 직접 연결 |
| 스키마 | 고정 스키마 | 유연한 스키마 |
| 관계 탐색 | 느림 (JOIN 연산) | 매우 빠름 (포인터 추적) |
| 적합한 용도 | 정형화된 데이터 | 연결 중심 데이터 |

## Neo4j의 핵심 구성요소

### 1. 노드 (Node)
노드는 그래프의 기본 엔티티입니다. 사람, 장소, 물건 등 어떤 것이든 노드로 표현할 수 있습니다.

```
(:Person {name: "홍길동", age: 30})
(:Movie {title: "인셉션", year: 2010})
(:Company {name: "네이버"})
```

### 2. 레이블 (Label)
레이블은 노드를 분류하는 태그입니다. 하나의 노드는 여러 레이블을 가질 수 있습니다.

```
(:Person:Actor:Director)  // 배우이자 감독인 사람
```

### 3. 관계 (Relationship)
관계는 두 노드를 연결하며, 항상 **방향**과 **타입**을 가집니다.

```
(:Person)-[:KNOWS]->(:Person)
(:Person)-[:ACTED_IN]->(:Movie)
(:Person)-[:WORKS_AT]->(:Company)
```

### 4. 속성 (Property)
노드와 관계 모두 키-값 쌍의 속성을 가질 수 있습니다.

```
(:Person {name: "홍길동", age: 30, email: "hong@example.com"})
-[:KNOWS {since: 2020, closeness: "친구"}]->
```

## Neo4j가 빛나는 사용 사례

### 소셜 네트워크
- 친구 추천
- 영향력 있는 사용자 찾기
- 커뮤니티 탐지

### 추천 시스템
- 협업 필터링
- 콘텐츠 기반 추천
- 하이브리드 추천

### 사기 탐지
- 이상 패턴 탐지
- 연결 분석
- 실시간 모니터링

### 지식 그래프
- 의미론적 검색
- 질의응답 시스템
- 데이터 통합

### 네트워크 관리
- IT 인프라 매핑
- 영향 분석
- 장애 추적

## Neo4j 제품군

### Neo4j Community Edition (무료)
- 오픈 소스
- 단일 인스턴스
- 기본 기능 제공
- 개발 및 학습용

### Neo4j Enterprise Edition (상용)
- 클러스터링 지원
- 고가용성
- 고급 보안
- 성능 모니터링

### Neo4j AuraDB (클라우드)
- 완전 관리형 서비스
- 자동 확장
- 백업 및 복구
- 다양한 요금제
