# Neo4j 완벽 가이드

Neo4j 그래프 데이터베이스의 모든 것을 배워보세요!

## Neo4j란?

Neo4j는 세계에서 가장 널리 사용되는 **그래프 데이터베이스**입니다. 관계형 데이터베이스와 달리, Neo4j는 데이터 간의 **관계(Relationship)**를 일급 시민으로 취급하여 복잡한 연결 데이터를 효율적으로 저장하고 쿼리할 수 있습니다.

## 왜 Neo4j인가?

### 1. 직관적인 데이터 모델
- 화이트보드에 그린 다이어그램이 곧 데이터 모델
- 노드(Node)와 관계(Relationship)로 자연스럽게 표현

### 2. 강력한 쿼리 성능
- 관계 탐색에 최적화된 네이티브 그래프 저장소
- 수십억 개의 노드와 관계를 실시간으로 탐색

### 3. Cypher 쿼리 언어
- SQL을 그래프에 맞게 확장한 직관적인 쿼리 언어
- 시각적 패턴 매칭으로 복잡한 쿼리도 간단하게

### 4. 풍부한 생태계
- 다양한 프로그래밍 언어 드라이버
- Graph Data Science 라이브러리
- 강력한 시각화 도구

## 이 가이드의 구성

### 초급 (Beginner)
Neo4j를 처음 접하는 분들을 위한 기초 가이드입니다.
- Neo4j 설치 및 환경 설정
- 그래프 데이터베이스 기본 개념
- 노드, 관계, 속성 이해하기
- 기본 Cypher 쿼리 작성

### 중급 (Intermediate)
기본기를 익힌 후 실무에 적용하고 싶은 분들을 위한 가이드입니다.
- 효과적인 데이터 모델링
- 고급 Cypher 쿼리 기법
- 인덱스와 제약조건
- 애플리케이션 통합

### 고급 (Advanced)
Neo4j를 마스터하고 싶은 분들을 위한 심화 가이드입니다.
- 그래프 알고리즘
- 클러스터 구성 및 운영
- 성능 최적화 및 튜닝
- 엔터프라이즈 보안
